06 Cómo funciona el modelo

Todo se reduce a estimar λ

Los goles son eventos raros: eso lo describe la distribución de Poisson. λ es los goles esperados de un equipo — con un buen λ, la Poisson calcula la probabilidad de cada marcador.

P(goles) para λ = 1.8  ·  distribución de Poisson

log(λ) = μ + α − β + host + elo + xg + valor
α − β fuerza de ataque menos defensa del rival
host ventaja de jugar como anfitrión
elo·xg·valor ranking, calidad de ocasiones y valor de plantilla

Interpretable: ordenar equipos por α da un ranking real de delanteras. + corrección Dixon-Coles para empates apretados (0-0, 1-1).

07 Cómo aprende y se entrena

Ajustar hasta explicar el pasado

  • Aprender = ajustar los parámetros hasta explicar bien miles de partidos reales.
  • Un optimizador (L-BFGS-B de SciPy) baja el error "cuesta abajo" hasta el mínimo.
  • Regularización para que no memorice rarezas; validación cruzada para elegir lo mejor.
  • No es una caja negra: es machine learning interpretable.
la prueba honesta · brier ↓ menor = mejor

¿De verdad funciona?

Se prueba prediciendo Mundiales pasados con datos que el modelo no vio, y se compara contra métodos simples.
